# 로드스터 물리 실험실

2세대 테슬라 로드스터의 2017년 발표 제원과 2026년 10월 15일 공개 시연을 고등학교 물리 I·II로 검증하는 인터랙티브 리포트입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 리포트 본체. HTML·CSS·JS가 한 파일에 들어 있고 외부 파일을 하나도 불러오지 않아, 인터넷 없이 브라우저로 열면 됩니다. 글꼴은 기기 기본 글꼴, 화면은 라이트 모드 전용이며 수식은 브라우저 기본 MathML로 그립니다. |
| `verify_physics.py` | 같은 계산을 Python으로 따로 구현한 교차 검증 스크립트(표준 라이브러리만 사용). `python3 verify_physics.py` |
| `CLAUDE.md` | 작업 지시서 |

## 구성

- **Part 1 리서치**: 2017 ↔ 2026 스펙 비교, 발표 퍼포먼스 수치, 개발·연기 타임라인, 참고 영상과 출처 간 교차 검증 표
- **Part 2 물리 분석**: 직선 가속, 최고속도와 배터리 에너지 수지, 코너링, 급제동, 냉가스 추진기, 공개 시연(램프·킥플립). 장마다 핵심 법칙 → 가정과 변수 → 수식 전개 → 한계와 극복 원리 순서
- **실험실 7개**: 드래그 레이스, 최고속도·에너지, 선회 한계, 제동 에너지 분배, 추력 벡터·탱크 예산, 더 램프(다운포스 에너지 장부), 점프
- **코드**: 페이지에서 실행 중인 물리 엔진 소스, JavaScript ↔ Python 결과 대조(30개 항목), 브라우저에서 직접 고쳐 돌리는 코드 실험실

### 더 램프 실험실

시연 영상의 곡면 램프(반지름 약 10.6 m, 끝 각 170°, 높이 약 21 m)를 거꾸로 오르는 차를 1 ms 간격으로 적분합니다. 흡입력은 운동 방향에 수직이라 일을 하지 않지만, 스커트 틈으로 새는 공기를 팬이 계속 퍼내야 하므로(P = ΔP·Q, 베르누이 틈 속도) 배터리 에너지를 씁니다. 실험실은 그 몫을 팬 전기에너지와 흡입 때문에 늘어난 구름저항으로 나눠 보여 줍니다. 시연 조건(4,700 kg중 흡입, 36 km/h)이면 들어간 에너지의 약 40 %가 다운포스 몫이고, 같은 흡입으로 5 km/h로 기어오르면 약 82 %가 됩니다.

## 기준과 한계

2026년 10월 21일 기준입니다. 2026년 수치 대부분은 테슬라 발표나 임원 인터뷰이며 독립적으로 측정된 값이 아닙니다. 공개되지 않은 값(질량 일부, 공기저항 계수, 배터리 용량, 스커트 틈 면적 등)은 가정이며, 페이지에 근거와 함께 표시했습니다. 테슬라·스페이스X와 관계없는 교육용 자료입니다.
